Privacy policy

Last updated: 18 November 2026

assistant is a private application used by a single person (the owner) with the owner's own Google accounts.

Data accessed

With the owner's consent, the app reads Gmail messages and Google Calendar events using read-only Google OAuth scopes. It cannot send, modify or delete email or calendar data.

How data is used

Data is used only to produce summaries, agendas and reminders for the owner. It is processed on the owner's own computer and may be sent to the owner's AI model provider (Anthropic) solely to generate those summaries. It is not sold, shared with third parties for advertising, or used to train models.

Storage

OAuth tokens are stored encrypted on the owner's computer. No Google user data is stored on any server operated for this app.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
